# design/

변경 이후 기준은 레포 `design/`이다. 변경 절차는 [기획 변경 관리](../AGENTS.md#기획-변경-관리)를 따른다.

기획서와 결정 로그는 칠석의 규칙과 용어로 설명한다. 다른 게임을 참고작으로 적는 대신 필요한 동작과 연출을 칠석의 문맥에서 직접 설명한다.

| 파일 | 내용 |
| --- | --- |
| `game-design.md` | 전체 기획 기준. 원본 문서 「칠석(가제) 기획안」을 Markdown으로 내보낸 사본에서 시작했다 |
| `perspective-core.md` | 시점 회전·투영·재배치 규칙, 수치, 구간 데이터 형식. 코드와 구간이 따르는 기준 |
| `cinematic-intro.md` | 도입 시네마틱 6컷, 필요한 그림, 프롬프트 |
| `decisions.md` | 기획 변경의 날짜, 내용, 이유, 영향 기록 |

`game-design.md`와 다른 노트가 충돌하면, 더 최근에 사람이 승인한 쪽을 따르고 다른 쪽을 고친다. 모르면 묻는다.
