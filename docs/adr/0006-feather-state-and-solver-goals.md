# ADR-0006. 깃털 수집 상태와 솔버 완료 조건

- 상태 — 채택 (2026-11-21)

## 맥락

별무리 구간에서 시점을 바꿔 무대의 뒷면을 살펴보는 보상으로 까치 깃털을 둔다. 구간 클리어와 전부 수집은 각각 검증하며, 엔딩의 오작교는 클리어할 때 확정한 누적 수집량을 반영한다.

## 결정

- 구간의 `F` 좌표마다 수집 마스크의 한 비트를 할당한다. 활성 시점에 견우의 발 월드 좌표가 해당 칸이면 같은 규칙 코드로 게임과 솔버에서 비트를 기록한다.
- 낙하 리셋과 다시 시작은 현재 구간 마스크를 초기화한다. `M`에 닿으면 수집분을 확정하고, 이미 클리어한 구간의 누적분은 보존한다.
- 솔버는 기본 경로와 수집 경로에서 각각 클리어 최소 회전 수, 전부 수집 후 클리어 최소 회전 수를 구한다. 두 경로 모두 정상 이동은 0, 성공한 회전은 1인 0–1 BFS를 사용한다. 수집 경로는 위치·시점에 마스크를 더해 같은 위치에서 수집분이 다른 상태를 구분한다.
- `M` 진입으로 구간을 종료한다. 전부 수집하지 못한 채 도달한 `M`은 완전 수집 탐색의 성공으로 세지 않는다.

## 결과

- 구간당 깃털은 3~5개로 한정한다. 클리어 회전 목표는 유지하고, 구간 검증에서 전부 수집 가능 여부를 별도로 확인한다.
- [ADR-0001](0001-pure-logic-shared-by-solver.md)의 순수 규칙 공유와 [ADR-0004](0004-zone-data-as-text.md)의 텍스트 원본 방식을 적용한다.
