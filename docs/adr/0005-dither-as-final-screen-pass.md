# ADR-0005: 디더링은 화면 마지막 패스에서 한 번만 건다

- 상태: 채택 (2026-11-20)

## 맥락
게임과 시네마틱 모두 1비트 디더링 화면이다. 그림이나 텍스처에 디더를 미리 구우면, 움직이거나 확대될 때 점이 뭉개지고 지글거리며, 컷마다 점 간격이 달라진다.

## 결정
- 모든 그림·텍스처·스프라이트는 흑백 그레이스케일 원본으로 둔다.
- URP Renderer Feature 하나(`DitherRenderFeature`)가 저해상도(기본 480×270)로 렌더한 화면에 Bayer 4×4 순서 디더와 2색 팔레트(먹 #1D1A17, 한지 #E8DFC8)를 적용하고 확대한다. 디더 격자는 화면에 고정한다.
- 연출 값(밝기, 디졸브 진행도, 반전, 내부 해상도, 보일링)은 `DitherSettings`에 모으고, 게임 코드와 Timeline이 이 값만 바꾼다.

## 결과
- 시네마틱 그림을 레이어로 나눠 움직여도 점 질감이 일정하다.
- 이미 디더링된 그림은 블러로 그레이스케일을 복원해서 써야 한다.
