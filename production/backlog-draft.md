# 칠석 기능 백로그 초안

기준일은 2026-11-21이다. 각 항목은 한 세션 분량이며 Bxx는 초안의 고정 ID다. 등록 후에도 ID를 유지한다. 실제 GitHub 번호는 생성기가 본문에 넣는다. 기획과 규칙은 [기획안](../design/game-design.md), [퍼즐 코어](../design/perspective-core.md), [시네마틱](../design/cinematic-intro.md), [진행표](../docs/progress.md)를 따른다.

- **제외한 작업**은 Unity 6.3 URP 초기화·기본 폴더·SampleScene·새 Input System 활성화·기본 패키지(`ea9c397`), Windows PC 배포 대상 확정(`af144e3`), Codex 하네스 이식(`984b329`, `807c04c`), 기획·Notion·감각 판단 규칙(`9ea46b0`~`ce437b2`)이다. 환경 이슈는 칠석용 asmdef·씬·빌드 프로필 확인과 열린 에디터 CLI 게이트 재검증만 담는다.
- **일정**은 11/22 코어·그레이박스 기반과 필수 원본, 11/23 게임 기능·에셋 적용·튜닝·QA, 11/24 빌드·배포·README·제출이다. 에셋 생성(사람)은 기능 구현과 병렬로 잡는다.
- **감축 제안**은 6구간을 기본으로 두고 먼저 B17을 `nice-to-have`로 내려 되돌아가기를 B18에 흡수한다. 그다음 B16을 내려 낙하 경로를 남은 구간에 흡수한다. 감축하면 B18의 선행 이슈를 실제 남은 직전 구간으로 갱신하고, 이후 사운드 → 추가 엔딩 연출 → 회전 이징 순으로 감축한다. 마지막 탑과 깃털 수에 따른 오작교는 남긴다. 핵심 6개가 끝나지 않으면 B53~B55는 보류한다. 칠성 기믹 감축 시 컷 5는 별 하나 반짝으로 돌아간다.
- **재실행** 시 본문의 고정 ID나 같은 제목의 기존 이슈를 재사용한다. 등록한 이슈의 일정·라벨·제목·선행 변경은 GitHub와 진행표에 따로 반영한다. [생성 스크립트](../tools/harness/create-backlog.ps1)는 초안을 검토한 사람이 자신의 터미널에서 실행한다.

검토 후 자기 터미널에서 `gh auth status --hostname github.com`으로 로그인 상태를 확인하고, 레포 루트에서 `powershell -NoProfile -File tools/harness/create-backlog.ps1`을 실행한다. 완료 출력의 Bxx와 실제 GitHub 번호를 확인한다.
