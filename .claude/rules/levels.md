# 구간 데이터 규칙

- 구간 데이터는 `zone-NN.txt` 텍스트 파일이다. 형식은 `design/perspective-core.md`의 "구간 데이터 형식"을 따른다. (ADR-0004)
- 구간을 고치면 **반드시** 헤더의 `intent`(의도한 풀이)와 `rotations`(목표 최소 회전 수 범위)도 맞춘다.
- 고친 뒤에는 `unity-quality-gate`로 `ZoneSolverTests`를 돌린다. 솔버가 "회전 없이 풀림"이나 "풀 수 없음"을 내면 구간을 고친다. 테스트 범위를 늘려서 통과시키지 않는다.
- 구간 사이 길(회전 잠금 평지)은 구간 파일에 넣지 않는다. 길과 구간 배치는 씬 셋업 메뉴가 맡는다.
- 크기는 최대 8×8×8. 점프 능력(1칸 오르기, 가로 1칸 틈 건너기)을 넘는 배치를 쓰지 않는다.
