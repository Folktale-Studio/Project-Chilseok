# 렌더링·시네마틱 규칙

이 지침은 이 폴더 아래 파일과 `Assets/Chilseok/Shaders/`, `Assets/Chilseok/Scripts/Cinematic/`에 동일하게 적용한다.

- 디더링은 화면 마지막 풀스크린 패스에서 **한 번만** 건다. 텍스처·스프라이트·시네마틱 그림에 디더를 굽지 않는다. 원본은 흑백 그레이스케일이다. (ADR-0005)
- 디더 격자는 화면 픽셀에 고정한다(카메라가 움직여도 격자는 그대로). 내부 해상도 기본 480×270, Bayer 4×4, 팔레트 먹 #1D1A17 / 한지 #E8DFC8.
- 연출용 값은 한곳(`DitherSettings`)에 모은다: 밝기, 디졸브 진행도, 반전, 내부 해상도, 보일링 강도. Timeline과 게임 코드가 이 값만 바꾼다.
- URP 17 Render Graph API를 쓴다. 바뀌었을 수 있는 API는 설치된 패키지 소스로 확인한다.
- Windows 플레이어 빌드에서 디더링과 시네마틱이 정상 표시되는지 확인한다. 컴퓨트 셰이더를 쓰지 않는다.
- 시네마틱 레이어는 쿼드를 깊이별로 세우고 원근 카메라로 움직인다. 움직임은 컷마다 핵심 하나만 둔다.
